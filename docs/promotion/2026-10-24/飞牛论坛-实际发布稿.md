# NAS Photo TV 体验版：用电视看飞牛相册，让回忆回到客厅

分享一个个人项目 **NAS Photo TV**：面向 Android TV 和电视盒子的飞牛相册客户端，目前是 **1.0.0-prototype 开发体验版，非飞牛官方客户端**。

照片备份进 NAS 以后，怎样让它们更经常被看见？旅行时拍下的风景、家人的合照、手机里留下的日常，其实都很适合在客厅的大屏幕上一起回看。NAS Photo TV 做的就是这件事：把飞牛相册带到电视上，用遥控器浏览照片，也可以让照片和时钟组成一页安静的应用内屏保。

## 用遥控器，慢慢翻相册

应用已接入真实飞牛相册数据，可以浏览媒体库、最近添加和相册，也能按年、月、日逐级找到某一天的内容。界面围绕电视横屏和遥控器设计：方向键移动、确认键打开、返回键回到上一层。比起围着手机看照片，大屏更适合一家人坐下来，聊聊照片背后的事情。

## 让画面占据主角

打开照片后可以全屏查看，左右切换，使用缩略图快速跳转，也可以开启幻灯片自动播放。需要看细节时，还有遥控器操作的 2 倍放大与平移。电视端支持本地收藏，方便下次继续找喜欢的画面；这些收藏保存在电视端，不会写回 NAS。

## 不翻相册时，留一页照片时钟

应用内提供多种时钟样式，可以配合照片轮播、极光动态或纯黑背景。它适合在打开应用的情况下，当作客厅里的照片时钟：看时间，也顺便看看那些平时不常打开的照片。

## 视频也能打开，先看设备能力

应用已接入 Media3 ExoPlayer，从 NAS 串流播放视频，提供播放暂停、快进快退和视频切换。能否顺利播放，仍取决于素材编码和电视、盒子的解码能力。尤其 4K、10bit、高帧率原片，可能超出设备规格；当前没有自动转码或降级选流，不承诺所有原片都能播放。

## 怎样体验

需要一台运行 Android 8.0 及以上系统的 Android TV 或兼容电视盒子，以及可访问的飞牛 NAS 和相册内容。建议先在同一局域网内体验，在应用设置中填写 NAS 地址、端口和账号信息，再测试连接。

项目源码：[SMTM-PH / NasPhotoTV](https://github.com/SMTM-PH/NasPhotoTV)

目前 GitHub Releases 暂无安装包。愿意动手的朋友可按仓库 README 构建 APK，再安装到电视或盒子；这仍是开发体验版，也尚未完成广泛机型兼容性验证。

如果你也想在电视上回看飞牛相册，欢迎关注这个方向。体验时遇到问题，可以在 GitHub Issues 中附上设备型号、Android 版本、fnOS 版本、复现步骤；视频问题再补充编码与分辨率，反馈会更容易定位。
