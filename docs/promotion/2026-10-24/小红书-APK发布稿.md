# 把飞牛相册搬上电视，回忆回到客厅（APK 已开放下载）

上次分享的 NAS Photo TV 有朋友留言说构建太麻烦，这次把安装包准备好了📦

APK 已经发布到 GitHub Releases，下载、拷 U 盘、电视上装好就能用，不用再自己跑构建。

🖼️ 大屏翻照片
接上飞牛相册就能在电视上翻照片：相册、最近添加，也能按年→月→日找某一天。全屏看图、幻灯片自动播放、2 倍放大，遥控器全程搞定。

🎬 NAS 视频直接播
真实解码 NAS 原片，进度条、快进快退、自动连播都有。4K/10bit 这类超规格素材能不能播取决于电视解码能力，播不了会告诉你原因、可以直接跳下一部。

🕰️ 不看电视时，它是一台相框
5 种时钟样式 × 照片轮播 / 极光 / 纯黑背景，空闲自动进入，任意键退出，带防烧屏处理。

📲 三步装上（见图 4）
1️⃣ GitHub 搜 NasPhotoTV 进 Releases
2️⃣ 下载 v1.0.0-prototype 的 APK（约 26 MB）
3️⃣ U 盘装进电视，或 adb install

先说清楚：Android 8.0+ 的电视/盒子，需与飞牛 NAS 同一局域网；1.0.0 开发体验版，非飞牛官方客户端；照片视频不出局域网。

装好欢迎回来说说你的电视型号能不能流畅跑，让这个客厅相册慢慢变好🌿
