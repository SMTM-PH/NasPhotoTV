# 把飞牛相册搬上电视，回忆回到客厅

照片备份进 NAS 后，是不是就很少再打开？📷

分享一个适合客厅大屏的个人项目：NAS Photo TV。它把飞牛相册带到 Android TV / 电视盒子上，用遥控器就能慢慢翻照片。

周末和家人坐在沙发上，重看一次旅行、找找以前的合照，比起一张张传手机，多了点一起看相册的感觉。

比较喜欢它的这几个方向👇

🖼️ 大屏翻照片
可以看相册、最近添加，也能按年→月→日找某一天。打开照片后全屏查看，左右切换、缩略图跳转，还能自动播放幻灯片。

🕰️ 照片＋时钟
应用内有多种时钟样式，搭配照片轮播、极光动态或纯黑背景。打开应用时，可以把电视当作客厅里的照片时钟。

🎬 回看 NAS 视频
已经接入真实视频播放，但是否能播取决于电视/盒子的解码能力。4K、10bit、高帧率原片不保证兼容，当前没有自动转码。

先说清楚体验门槛：这是 1.0.0-prototype 开发体验版，非飞牛官方客户端。需要 Android 8.0 及以上的 Android TV 或兼容盒子，以及能访问的飞牛 NAS；建议先在同一局域网体验。屏保是应用内功能。

源码在 GitHub：SMTM-PH/NasPhotoTV。目前 Releases 暂无安装包，需要按 README 自行构建 APK，适合愿意动手的朋友先尝试。

你会更想在电视上翻相册，还是让它轮播照片？也欢迎反馈设备兼容情况，让这个客厅相册慢慢变好。
