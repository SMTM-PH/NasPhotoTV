# NAS 里的照片，想让家人更经常看到

最近重新整理了 **NAS Photo TV** 的电视端界面，分享一版开发设计预览。

首页只留「回忆、图库、相册」三个入口。大幅照片做背景，下方左右挑选相册和往年日期回忆，按确认就能播放一组照片。

看图时先把画面留给照片，需要时再呼出收藏、播放、信息、放大和关闭。返回首页，还能接着看刚才选中的集合。

这次也加了一个很在意的设置：**客厅展示相册**。首页回忆和照片屏保只使用自己明确勾选的相册，空相册不会拿其他最近照片来补。正常图库浏览不受影响。新安装默认关闭自动屏保，已有开关选择保留，预览也不会自动打开它。

配图里的彩色相册花是 AI 辅助生成的新图标设计稿，尚未接入 APK。

当前是个人开发的设计预览，非飞牛官方客户端，尚未作为新正式版本发布。界面配图来自模拟器离线示例，本轮真实电视和真实 NAS 还没有复验。

项目：[SMTM-PH / NasPhotoTV](https://github.com/SMTM-PH/NasPhotoTV)

设计预览与体验说明：[界面改版分支](https://github.com/SMTM-PH/NasPhotoTV/tree/codex/tv-gallery-ui)，安装方式见分支 README。
