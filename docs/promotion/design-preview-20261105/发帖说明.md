# 发帖与素材使用说明

本包整理于 2026-11-05，供作者自行发布。它是设计预览的文字与图片素材，不是新的正式安装版本。

## 选择稿件

- **论坛发布稿.md**：完整设计说明，六张配图使用 `images/` 相对路径。在支持 Markdown 的编辑器中便于预览和继续编辑。
- **论坛外链版.md**：同一篇长文，配图替换为 GitHub 固定提交链接，适合支持外链图片的 Markdown 论坛。
- **短版文案.md**：适合社交平台、动态或帖子摘要；按平台逐张上传配图。

论坛若不支持外链图片，请先上传 `images/` 中的六张 PNG，再把稿件里的图片地址换成论坛返回的地址。相对图片路径通常不能直接在论坛上显示。发布前使用平台预览，确认六张图均能显示。

## 发布时保留的信息

保留「开发设计预览」「非官方飞牛相册客户端」「模拟器离线示例」「本轮真实电视与真实 NAS 尚未复验」和「图标尚未接入 APK」这些说明。帖子中的安装入口指向设计分支的说明，旧 GitHub Releases 不代表已包含这次改版。

屏保为应用内功能，新安装默认关闭自动屏保；它不是 Android 系统级屏保。视频兼容性取决于设备与素材，不承诺 4K、10bit 等格式全兼容。

若发布平台要求标注 AI 内容，按实际情况说明：彩色相册花图标经过 AI 辅助生成；前五张界面图是应用实际渲染的截图。

摄影素材署名与许可见 [图片来源.md](图片来源.md)。原图版权归摄影师所有；不要把这些摄影图片单独作为图库商品分发。
