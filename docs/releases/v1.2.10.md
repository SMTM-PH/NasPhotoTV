## 用户反馈

> 现在点文件夹，会把主文件夹，子文件夹，孙文件夹全部都列在一起，如果能分层列出会更好

## 问题

1.2.6 起为了「不吞掉子文件夹」，把 `FnOsFolders` 递归读到的整棵目录树
（扫描根目录 + 所有层级的子目录）一次性铺进文件夹 Tab 的网格。1.2.8 / 1.2.9 修好
子目录读取与封面后，目录数量进一步变多（本机实测 156 个目录），
根 / 子 / 孙目录混排时完全看不出归属关系，遥控器要在一长串同名卡片里找目录。

`NasFolder` 本来就带 `parentId` / `depth`，但外壳把它映射成 `Album` 时只留下了一句
「子文件夹 · 路径」的 subtitle，层级关系在 UI 层丢了，所以只能平铺。

## 实现

- **`Album` 新增 `parentId` / `depth`**（默认空 / 0，其它相册类型不受影响）：
  新增纯函数 `folderAlbum()` 统一映射，id 与 parentId 都带 `folder:` 前缀，
  `subtitle` 改回完整路径。
- **`FolderHierarchy`（纯 Kotlin，可单测）**：按 parentId 建索引，提供
  `childrenOf(parentId)` / `hasChildren` / `parentOf` / `breadcrumb`。
  父目录缺失（刷新中途、旧缓存）时把孤儿目录挂到根层，保证任何目录都有入口；
  父链成环时立即收尾，不会卡死 UI。
- **`FoldersTab` 改为逐层浏览**：
  - 根层只显示扫描根目录；卡片显示「N 个子文件夹」或「N 项」；
  - 点有子目录的卡片下钻一层，点叶子目录直接打开该目录的照片（行为不变）；
  - 进入目录后网格首两格固定为「返回上一级」与「查看本目录照片」，
    保证有子目录的文件夹也能看到它自己的媒体；
  - 标题下增加面包屑「文件夹 › Photos › DJI_001」，网格行数只统计当前层；
  - 遥控器 BACK 在目录树里逐层向上，回到根层才退出 Tab；
    返回时焦点落回「进入该目录的那张卡」。
- **导航状态上提到 `LibraryScreen`**（`rememberSaveable`）：进入相册详情 / 切换 Tab
  只销毁 Tab 组合，不会一进详情就退回根目录；账号切换或刷新后当前目录失效时自动回根层。
  BACK 统一由外壳处理，不与多个 `BackHandler` 抢注册顺序。
- `AlbumCard` 增加可选 `secondaryText`，`FolderNavCard` 提供与相册卡同尺寸、同焦点态的
  导航卡（用图标代替封面，避免伪造目录封面）。
- `DesignPreviewActivity` 离线示例补成根 / 子 / 孙三层 + 第二个扫描根目录，
  供模拟器逐层下钻验证。

## 验证

- `:app:testDebugUnitTest` / `:app:assembleDebug` / `:app:assembleRelease`
  **BUILD SUCCESSFUL**；**142 个单元测试全绿**（新增 `FolderHierarchyTest` 9 例：
  映射保留层级、根层只列扫描根目录、逐层只列直接子目录、分支/叶子判定、
  父链上溯、面包屑顺序与成环保护、孤儿目录兜底、空数据安全），失败/错误/跳过均为 0。
- **Android TV 模拟器实测（1080p，`DesignPreviewActivity --ei tab 3` 离线根/子/孙三层示例）**，
  用 `uiautomator dump` 逐屏核对文本与焦点落点：
  - 根层只出现 `Photos` / `Video` 两张卡（`2 个扫描目录`），分别标注
    `3 个子文件夹` / `455 项`，根/子/孙不再混排；
  - 进入 `Photos`：面包屑 `文件夹 › Photos`、`3 个子目录`，网格前两格为
    `返回上一级`（副标题 `返回扫描目录`）与 `查看本目录照片`；
  - 再进入 `DJI_001`：面包屑 `文件夹 › Photos › DJI_001`、`1 个子目录`，
    `返回上一级` 副标题变成 `返回「Photos」`，孙目录 `夏天` 正常列出；
  - 遥控器 BACK 依次 `孙层 → Photos（焦点落回 DJI_001 卡）→ 根层（焦点落回 Photos 卡）→ 首页`；
  - `查看本目录照片` 进入 `Photos` 的 `3 张照片` 详情页，BACK 回来仍停在 `Photos` 子层，
    不会退回根目录；叶子目录 `Video` 仍是点一下直接进照片详情；
  - 第二行卡片聚焦时网格自动上移，`MobileBackup` / `DJI_001` 的标题与数量完整可见；
  - logcat 无 `com.nasphoto.tv` 的 `FATAL EXCEPTION` / 崩溃。
