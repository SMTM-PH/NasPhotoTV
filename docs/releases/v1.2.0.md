# NAS Photo TV 1.2.0 发布说明

- 发布日期：2026-11-08
- 版本：`1.2.0`（versionCode 6）
- 安装包：`app-debug.apk`（debug 签名，可直接 `adb install -r` 覆盖 1.1.x）
- 分支：`main`（由 `codex/tv-gallery-ui` 合入）

## 亮点

### 首页展示飞牛 AI 智能分类
首页「客厅相册」改为读取飞牛 `ai-smart-rec` 的**场景 / 事物分类**（天空云彩、山、登山徒步……），实测 80 个分类，封面直接取分类 poster。点开分类或「播放这个分类」时才通过 `magic-search` 拉取媒体，避免启动预取几十个相册。

### 图库按全库年份分组
启动改为取整库（实测 **5281 项、11 个年份，2015–2026**），年 → 月 → 日逐级浏览；此前只取最近 1000 项，年份只剩 2026。

### 人物相册真正出图
`ai-person/list` 只返回 `faceId`，头像改用 `/p/api/v1/stream/face/{faceId}`（实测 `image/jpeg`）；卡片头像区改为 **1:1 正方形铺满**，名字与张数固定排在下方，不再只有文字。

### 4K 播放不再周期性卡顿
根因：ExoPlayer 默认前向缓冲 50 秒且不限字节，75–130 Mbps 的 4K 原片需要 470 MB 以上，而本机 Java 堆上限 192 MB，导致持续 GC 与 1–3 秒停顿。
修复：`DefaultLoadControl` 缓冲改为 **48 MB / 8–20 秒**封顶，开启解码失败回退（不使用异步 MediaCodec 队列，避免 MTK Android 9 崩溃）。

实测（75 Mbps 4K HEVC，1920×1080@60）：帧间隔中位数 **16.67 ms**、平均 16.86 ms、p99 33.5 ms、最大 46.5 ms，**无 >50 ms 卡顿帧**，稳定后缓冲约 5.3 秒。

### 看图交互
- 胶片条选中后按确认 → 收起全部浮层、焦点回到画面，真正全屏；再按确认调出工具条。
- 视频封面提示由「回车」改为「确认」。
- 详情页标题压缩为 30sp 单行 + 数量同行，底部提示条不再遮挡最后一行。

### 图标
`nas-photo-tv-icon-v2` 生成 mdpi–xxxhdpi 启动图标；TV 横幅 320×180 **只保留图案、去掉文字**。

## 已知限制
- 电视为 **100 Mbps 有线网口**：75 Mbps 的 4K 可稳播；超过 ~100 Mbps 的原片实时串流会间歇缓冲，需转码或本地缓存。
- 智能分类、人物依赖 NAS 已开启并完成 AI 识别；接口失败时首页会显示提示而不是空列表。
