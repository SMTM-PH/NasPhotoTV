## 用户反馈

> 1. 网络不太好的情况下在播放幻灯片时两张照的间隙会出现锯齿样图片，观感不太好，
>    能否取消这个显示，直接等下一张照片加载完成后直接显示下一张照片。
>    或者把这个锯齿样的图标换成转圈加载的样式。
> 2. 希望能像 showcase 一样加入幻灯片切换动画。
> 3. 播放视频时有时会出现方向不一致的情况，能否修正一下，或者添加手动旋转的选项。

## 一、两图间隙的锯齿图（已修复）

**根因**：`MediaImage` 的 `SubcomposeAsyncImage` 在 loading / error 两个槽位都画了
`Placeholder` —— 渐变底 + `Icons.Outlined.BrokenImage`（锯齿状「破图」图标）。
幻灯片一换页，新舞台立刻进入 loading，这张图标就会在两张照片之间闪一下；
网络越慢闪得越久。屏保的 `Crossfade` 也一样，慢网络时新分支先亮出占位图。

**实现**（两条方案都做了，取长补短）：

- `MediaImage` 新增 `MediaPlaceholder`：
  - `SPINNER`（卡片 / 缩略图默认）：渐变底 + `CircularProgressIndicator`，
    **彻底移除锯齿破图图标**；error 槽位只保留渐变底，也不再画图标。
  - `HOLD`（全屏看图舞台、全景舞台、屏保）：完全透明，**保留下层（上一张）画面**；
    只有加载超过 600ms 才叠一个很轻的转圈，慢网络有反馈、秒开不打扰。
- **换页前预加载**：`PhotoViewerState.peekNextPhoto()` 只看不动 index；
  幻灯片 tick 先 `ImageLoader.execute()` 把下一张解码进 Coil 内存缓存，再 `advanceSlideshow()`。
  预加载尺寸用 `effectiveImageWidth()` 与真正显示时同一把尺子（Coil 缓存键含尺寸），
  全景图按 4096 请求、普通全屏按 1920。最长等 8 秒，超时 / 失败仍换页，
  由 HOLD 占位继续保留上一张，不会把幻灯片卡死。
- 屏保 `ScreensaverPhotoBackground` 同样提前解码下一张，尺寸与显示侧一致。

效果：正常情况「等下一张加载完 → 直接换成下一张」；极慢网络一直显示当前照片，
中间不再出现渐变方块 + 锯齿图标。

## 二、showcase 风格切换动画（已加入）

- 幻灯片自动换页：`AnimatedContent` 改用 **900ms 缓慢叠化**（不再左右滑），
  两张照片在叠化期间同时在树上，HOLD 占位让上一张一直可见；
- 每张照片在 5 秒停留里用 `Animatable` 从 1.0 缓缓放到 **1.05**（`ShowcaseZoom`），
  配合叠化就是「画面在呼吸」的 showcase 观感；
- 暂停 / 2× 放大查看时立刻回到 1.0，不干扰放大平移与全景坐标；
- **手动左右翻页仍保留原方向滑动**，两种交互不会互相串味；
- 屏保原本就有 2s 叠化 + Ken Burns，保持不变。

## 三、视频方向（修正 + 手动旋转）

**修正**：

- `onVideoSizeChanged` 读取 `VideoSize.unappliedRotationDegrees`（media3 1.5 标记为
  deprecated、正常路径恒 0，但少数渲染路径 / 老解码器会留下非零值）：
  归一化到 0/90/180/270，90/270 时交换宽高再交给 `isPortraitPlayback`，
  避免「元数据说是横屏、实际按竖屏渲染」这类判定抖动；非零时由 UI 补旋一次。
- 换片时清掉上一条的旋转状态（`decodedSize` / `autoRotationDegrees` / 手动覆盖），
  不会「转了这一条、后面全跟着转」。

**手动旋转选项**：

- 新增 `VideoRotation`（不旋转 / 向右 90° / 180° / 向左 90°），
  进 `PlaybackSettings.rotation` 并持久化（`pb_rotation`）；
  设置页「视频播放」新增「画面旋转」一行，← → 切换档位，右栏摘要同步显示。
- 播放器内按 **MENU** 逐档旋转当前视频（**INFO / 红键**同效），**绿键**复位到设置默认值，
  **黄键**循环竖屏适配（该选项仍可在设置里改）；控制条实时显示「已旋转 90°」。
- 旋转 90/270 时，PlayerView 先按 `rotationFitScale = 短边/长边`（16:9 屏为 0.5625）
  缩到「转过来仍能完整放进屏幕」，再用 `graphicsLayer.rotationZ` 旋转，
  **不裁切、不拉伸**，两侧留黑。
- 播放器画面改用 **TextureView**（`res/layout/player_view_rotatable.xml` 的
  `app:surface_type="texture_view"`）：SurfaceView 的内容由系统单独合成，
  父级 View 的旋转不作用于画面本身，按键会「没反应」；TextureView 走 View Canvas，
  Compose 的 graphicsLayer 变换才真正生效。NAS 原片无 DRM，可以放心用。

> ⚠️ MENU 键原先用于循环「竖屏适配」，本版改为「旋转画面」；竖屏适配改到黄键，
> 设置页「竖屏画面」一行仍可随时改。遥控器没有彩键时以设置页为准。
