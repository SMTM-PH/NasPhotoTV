# NAS Photo TV 1.2.3 发布说明

- 发布日期：2026-11-13
- 版本：`1.2.3`（versionCode 9）
- 安装包：`NasPhotoTV-1.2.3-debug.apk`（debug 签名，可直接覆盖 1.2.x）
- SHA-256：`030142a855c3f2c99c9dc6a878c0830c8b790d36a7c827c70317148d01aba0ee`

本版同时包含未单独发布的 1.2.2（4K / 高密度电视适配 + 设置页卡顿修复）。

## 反馈问题

1. 照片从 2000 年开始，但「图库」只显示最近 9 年，2000–2017 不显示。
2. 「人物」里有几千张照片，点进去只显示 100–300 张。
3. 相册点进去几千张没法看，希望按年份分组。
4. 希望增加「按文件夹」和「按地理位置」浏览。

## 一、图库只显示最近几年（已修复）

**根因**：飞牛 `gallery/getList` 单页最多返回 **500** 条。旧代码一次传 `limit=20000`，
服务端只回最新 500 张，所以只覆盖最近几年。实测本机全库 **5294 项、11 个年份**。

**修复**：按 `offset` 逐页拉全（`hasNext`/满页判定），直到取完或达到上限。
实测「图库」从 500 项变为 **5294 项**，并显示出 2017、2015 等更早年份（此前最早只到 2018）。

## 二、人物只显示一两百张（已修复）

**根因**：旧实现只看人物时间线的**前 30 天**、每天最多 200 张，且单日内不翻页。
实测「老婆」共 516 张、时间线 48 天，因此只能取到一小部分。

**修复**：
- 遍历**完整时间线**（所有有照片的日子）；
- 单日内按 `offset` 继续翻页直到该天取完；
- 严格使用服务端要求的**冒号日期格式**（`2026:10:24 00:00:00`，用短横线会报 `invalid params`）。

实测「老婆」由约 300 张变为 **436 张**（剩余为视频，属于不同接口口径），并带年份分组表头。

## 三、相册 / 人物详情按年份分组（已实现）

详情页（相册、文件夹、人物、智能分类共用同一网格）在照片跨年份时，自动插入
**「YYYY 年」**分隔行，向下滚动即按年份分段浏览；年份表头不参与焦点，遥控器操作不受影响。

## 四、按文件夹浏览（已实现）

新增「相册 → 文件夹」分类：
- 目录列表取自 `photo/folder/list`，显示真实张数（实测 Photos 4839 项、Video 455 项）；
- 打开目录用 `folder_view/getFileList`（参数 `folderId` + `folderPath`）分页拉全；
- 详情同样支持年份分组。

## 五、按地理位置浏览（本轮未交付，说明原因）

飞牛的地点接口 `/p/api/v1/map/*` 中，`preview/initCenter`、`preview/mapBoundary` 可正常返回，
但真正列照片/地点的 `map/timeLine`、`map/photoList`、`map/getIds`、`previewAllPoint`
无论怎样组合参数（时间范围、时区、地图边界、驼峰/下划线）服务端一律返回 **invalid params**，
判断为官方客户端私有协议、Web 端未暴露。需要抓取官方客户端「地点」页的请求后再实现，
本轮不发布半成品入口。

## 六、Android 7.x 安装失败（已修复）

反馈：Android 7.1.2 盒子安装提示「解析安装包出现问题」。

**根因**：APK 的 `minSdkVersion` 是 **26（Android 8.0）**，系统低于 8.0 会直接拒绝解析安装包。

**修复**：`minSdk` 降到 **24（Android 7.0）**，并开启 core library desugaring
（`desugar_jdk_libs`），把 `java.time` 等 API 26 才有的类脱糖给 7.x 使用。
实测生成的 APK `minSdkVersion=24`，可覆盖 Android 7.0/7.1.2。

## 七、幻灯片背景音乐 + 手机上传（已实现）

- 设置 →「屏保与待机 → 背景音乐」：打开面板后会显示一个**局域网地址**（如 `http://192.168.x.x:8899/u/xxxxxx/`）；
- 手机连同一 Wi‑Fi，用浏览器打开该地址，选一个音频文件上传即可（支持 mp3 / m4a / aac / flac / wav）；
- 上传成功后，**幻灯片播放和屏保**都会循环播放最新上传的那首；面板里可开关音乐、刷新列表；
- 上传服务只在面板打开时运行（随机 token 路径、只接受局域网访问、单文件上限 300MB），关闭面板即停止，平时不占端口。

实测：上传 132KB wav → 文件落到 App 私有目录 → 屏保预览时 ExoPlayer 起播
（AudioTrack state=started, 22050Hz, 已获得音频焦点）。
