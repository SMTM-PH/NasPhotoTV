## 反馈与协议取证

用户试用 1.2.7 后反馈：相册的文件夹只有主目录，没有子目录；图库仍只有最近 9 年，
2000–2017 年没有出现。

1.2.6 的目录修复依据推测的返回字段，模拟器验证使用手工示例数据，未验证真实子目录请求。
这次直接读取 NAS 当前提供的飞牛官方 Web 前端 JavaScript，确认以下协议：

| 功能 | 接口与参数 | 返回值 |
|---|---|---|
| 扫描根目录 | `photo/folder/list` | `list`，含根目录路径及计数 |
| 直接子目录 | `folder_view/getFolderList`；`folderPath`、`desc=false`、`orderBy=2` | `list`；子项含 `name`、`path` |
| 目录媒体 | `folder_view/getFileList`；`folderPath`、`desc=true`、`orderBy=0`、`offset`、`limit` | `list`、`total`；不包含子目录 |
| 图库时间线 | `gallery/timeline` | 按年/月/日组织的日期与条目数量 |
| 图库媒体 | `gallery/getList`；`start_time`、`end_time`、`offset`、`limit`、`mode=index` | 对应时间范围内的媒体 |

目录和图库接口定义在官方前端资源 `rexirLy2OngMLcaj2.js`，目录调用在 `CjL6t_lGV4YJ2Kc1.js`；
图库时间线调用在 `DrmU7TcPSLdckscQ2.js`、`XPOBuNOhKVjDE-Zr.js`。
资源来自 NAS 自己提供的 `/p/` 页面，不需要修改 NAS 上的媒体或扫描配置。

## 实现

- 目录列表改用专用子目录接口，递归读取各层目录；目录 ID 由完整路径生成，保留大小写。
  点进子目录时仅按该目录路径读取媒体，避免带上扫描根目录的 `folderId` 后查回根目录内容。
- 图库全量读取先获取时间线，逐年读取并按时间线数量核对；遇到分页异常则按天补齐。
  不再以开发 NAS 的样本规模设定 20,000 项上限，也不因服务端短页缺少分页标记而直接结束。
  如果仍无法读全，则报错，避免静默展示缺失年份的结果。
- 子目录接口失败与合法的空目录分别显示；取消请求会向上传播。
- 目录递归放在图库就绪后继续加载，文件夹页先显示读取状态，避免深层目录阻塞整个首页。
  子目录接口不返回媒体计数时显示「子文件夹」，不把未知数量标成「0 项」。

## 验证

- **真实 NAS，只读签名 API 请求**：时间线共 717 个日节点、11 个年份；按年份范围分页读取
  **5294 / 5294 项**，每年的媒体数量均与时间线一致，媒体日期年份错归 0 项。
  年份包含 2015、2017–2026，其中 2015 年 1 项、2017 年 136 项。
- **真实目录递归**：扫描根目录 2 个、子目录 154 个，共 **156 个目录**，最大深度 8；
  所有目录请求成功，耗时约 26 秒。`PhotoLibrary` 自身无媒体但含更深层目录，已确认需要继续递归。
- **请求链路回归**：新增 `GalleryLoadingTest` 11 例覆盖 2000–2026 年、50,001 项、短页无分页标记、
  异常分页按日补齐、不完整读取报错、错误和取消传播；`FolderTreeTest` 改为 7 例真实协议形态的
  根目录 → 子目录 → 更深层目录请求测试，不再仅测试虚构的嵌套 JSON。
- **构建通过**：`./gradlew --no-daemon :app:testDebugUnitTest :app:assembleDebug :app:assembleRelease`，
  `BUILD SUCCESSFUL`；**116 个单元测试通过，失败/错误/跳过均为 0**，release 的必要 lint 检查通过。
  原先只验证分页布尔判定的 8 个测试随旧分页逻辑移除，改用实际请求链路验证。
- **包校验**：`apksigner verify --print-certs` 成功，正式证书与 1.2.7 release 一致；
  `aapt dump badging` 确认 `versionName=1.2.8`、`versionCode=14`、`minSdk=24`。
- **Android TV 14 模拟器（1080p）**：调试包连接真实 NAS 后，图库显示 11 个年份、5294 项；
  遥控器可进入 2017 年，并从 2015 年下钻至月份和打开照片。示例图库中的 2000 年照片也可打开。
  文件夹列表显示 156 个目录，打开四层深的子目录后显示 18 张照片和 1 个视频。
  打开照片再返回，焦点回到原目录。未发现崩溃，正式包已验证可从电视入口启动。

本机目录为 SMB 共享盘，Gradle 文件哈希缓存锁不被文件系统支持；构建使用本机临时目录中的
同份源码，macOS JDK 17 / Android SDK 35。原工程 `local.properties` 已恢复。

用户 NAS 上 2000–2017 年照片的最终展示仍需使用本轮安装包连接用户数据确认。
