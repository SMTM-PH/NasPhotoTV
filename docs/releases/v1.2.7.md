## 新增：在线更新

用户反馈「什么时候加个在线更新」。本版按确认的方案实现：

- **更新源** = GitHub Releases 官方 `latest` API + **可配置备用地址**（镜像 / 反代 / 自建，返回同结构 JSON 即可）；
  下载还可叠加一个**镜像前缀**，避开国内电视访问 `github.com` 不稳的问题。
- **行为 = 手动确认**：检查 → 确认下载 → 确认安装，每步都要遥控器按一次确认，
  绝不自动下载、自动安装，也不会在看图/屏保时弹窗。
- **检查 = 设置页手动 + 启动静默检查（可关）**：启动时每天最多查一次，只把结果写进设置页状态卡片，
  不提示、不下载；「设置 → 关于 → 启动时自动检查」可关闭。

### 入口

设置 → 关于，新增四行：

| 行 | 作用 |
|---|---|
| 在线更新 | 按确认走状态机：`检查更新` → `下载 vX.Y.Z` → `安装 vX.Y.Z`；已是最新时显示 `已是最新 · 再检查` |
| 启动时自动检查 | 开关，默认开，每天最多一次 |
| 更新源地址 | 文本输入，留空 = 官方 GitHub API；可填镜像/反代完整 URL |
| 下载镜像前缀 | 文本输入，可选，例如 `https://mirror.example/` 会拼在 APK 下载地址前 |

右栏「关于」面板新增一张**在线更新状态卡片**：当前版本、检查结果、下载进度条、更新说明摘要、
当前更新源与镜像状态，以及操作提示。

### 实现要点

- **网络隔离**：用独立的 `OkHttpClient`，绝不复用 `FnOsTransport.client`
  （那个会注入 NAS 的 AccessToken 与自签证书信任，拿去请求外部服务器会把 NAS 凭据发出去）。
- **签名匹配**：Release 页同时提供 debug / release 两个包，签名不同、不能互相覆盖安装。
  App 运行时读取自身 APK 签名 SHA-256，与正式证书
  `e63c6b9d…` 比对，只下载与当前安装签名一致的那个包；匹配不到对应包时报错而不是装错。
- **安装**：`REQUEST_INSTALL_PACKAGES` 权限 + `FileProvider`（`cache-path updates/`）把私有目录里的
  APK 以 `content://` 交给系统安装器，用户还需在系统界面上确认一次。下载包落在 app 私有 cache，
  每次下载前清掉旧包，避免装到旧版本。
- **版本比较**：`tag_name` 与 `BuildConfig.VERSION_NAME` 按数字段语义化比较
  （`v1.2.10 > v1.2.9`，不是字符串比较）。
- **持久化**：更新偏好（自动检查 / 更新源 / 镜像 / 上次检查时间）随其它设置一起落盘；
  「恢复默认设置」会一并还原。

### 局限

- 这是「检查 + 下载 + 调起系统安装」，**不是静默自动升级**：安装仍需用户在系统界面确认，
  且 Android TV 首次会要求授予本应用「安装未知应用」权限。
- 更新源与镜像地址需要能返回 GitHub Releases 同结构 JSON / 提供 APK 直链；
  如果电视完全无法访问外网，可把地址指向自建服务或局域网 NAS 上的文件。
- 1.2.6 及更早版本没有更新模块，需先装一次本版；从 1.2.8 起才会真正提示「发现新版本」。
- 静默检查失败（无网络 / 更新源不通）不会打扰用户，右栏会显示「尚未检查」或「检查失败」，
  可手动重试。
