## 用户反馈

> 1. 相册点文件夹，会把所有的子文件夹都显示出来，但照片的缩略图不能显示，
>    点击具体照片时大照片也不能显示出来。
> 2. 相册点相册时，光标移到第二行照片，照片位置没有上移，
>    造成照片只显示上半部分，照片下面的文字也没显示。

## 根因与协议取证

1.2.8 按飞牛官方 Web 前端把目录树改成 `folder_view/getFolderList` 递归读取后，
**子目录已经能全部列出**，但目录里的媒体和封面仍然空白。

这次直接读取 NAS 自身提供的前端资源（`/p/` 页面下的 JS bundle），定位到两处：

| 现象 | 前端实现 | 1.2.8 Android 端的问题 |
|---|---|---|
| 目录内照片空白 | `folder_view/getFileList` 的条目常**不带** `additional.thumbnail`；前端 `XPOBuNOhKVjDE-Zr.js` 用 `getPhotoUrl({id, photoUUID, size})` 兜底 | `parseMedia` 只认 `additional.thumbnail.*Url`，全部字段为空 → 卡片占位图、大图也是空 |
| 目录卡片无封面 | 前端 `POST /api/v1/folder_view/cover`，按 `currentPath + dirNames` 批量取 `{dirPath, cover:[{id,uuid}], defaultCover}`，再用 `/p/api/v1/stream/p/t/{id}/xs/{uuid}` 拼封面 | 构造文件夹 Album 时把 `coverUrl` 写死成空字符串 |

`getPhotoUrl` 的算法见 `DMsxwg1v8l6DUDoj2.js`：
`thumbnailUrlPrefix + "p/t/${id}/${size}/${photoUUID}"`（视频为 `v/${id}`）。
本机 NAS 用 `trim-cli photos preview 6491 --size s/o` 复核过该地址形态完全一致：

```
http://localhost:5666/p/api/v1/stream/p/t/6491/s/15200454-e34b-42e4-ab1b-b5d028fb1ded
http://localhost:5666/p/api/v1/stream/p/t/6491/o/15200454-e34b-42e4-ab1b-b5d028fb1ded
```

第二个问题是焦点滚动：`scrollGridTo` 在卡片未完整可见时执行
`animateScrollToItem(((row - 1).coerceAtLeast(0)) * columns)`。
聚焦**第二行**（row=1）算出来是第 0 项，而网格本来就在顶部 —— 这一步等于没滚，
于是第二行贴着屏幕下沿被裁掉半张，卡片底部的标题/日期也看不见。

## 实现

- 新增 [MediaUrls.kt](../app/src/main/java/com/nasphoto/tv/data/MediaUrls.kt)：
  把缩略图 / 大图 / 实况片段地址解析收敛成纯函数，兼容
  `additional.thumbnail`、顶层 `thumbnail`、顶层 `mUrl/sUrl/originalUrl` 三种形态，
  并在缺字段时按官方算法用 `id + photoUUID` 拼 stream 地址（缩略图 `s`、大图 `o`、
  RAW 用 `m`、视频 `v/{id}`、实况片段 `v/{id}`）。反代子路径由 `absoluteUrl` 统一处理。
- `MediaItem` 新增 `filePath`；`albumCoverUrl` 在封面缺失时，用整库时间线里
  同目录前缀的照片缩略图兜底，不再为每个目录额外发一轮请求（本机有 156 个目录）。
- `FnOsFolders` 新增**目录封面批量读取**：按父目录分组、每批最多 50 个 `dirName`
  调 `POST /p/api/v1/folder_view/cover`，把 `{cover|defaultCover:[{id,uuid}]}`
  拼成 `xs` 封面；接口失败/旧版本没有该端点时静默降级，绝不影响目录树读取。
- `NasPhotoTvApp` 把文件夹卡片的 `coverUrl = ""` 换成真实封面，
  `FoldersTab` 统一走 `albumCoverUrl` 兜底链。
- `scrollGridTo` 改为按**实际溢出量**做最小滚动（额外留 12%／至少 16px 给焦点放大
  与卡片底部文字），焦点跳到未组合的行时按行首定位；
  滚动量抽成 `gridScrollDeltaPx` 纯函数以便回归测试。
- 版本升至 1.2.9（versionCode 15）。

## 验证

- `./gradlew --no-daemon :app:testDebugUnitTest :app:assembleDebug :app:assembleRelease`
  **BUILD SUCCESSFUL**；**133 个单元测试全绿**（新增 `MediaUrlsTest` 9 例、
  `FolderCoverTest` 3 例、`GridScrollTest` 5 例），失败/错误/跳过均为 0。
- 真实 NAS 只读复核：`trim-cli photos folders` 返回扫描根目录 2 个；
  `photos search IMG` 与 `photos preview 6491 --size s/o` 确认
  `{id, photoUUID, size}` 拼出的 stream 地址与服务端一致。
- `apksigner verify --print-certs` 通过，正式签名与 1.2.7/1.2.8 release 一致；
  `aapt dump badging` 确认 `versionName=1.2.9`、`versionCode=15`、`minSdk=24`。
- ⚠️ CLI 的 OAuth 代理对 `folder_view/*` 返回 403，无法用它直接抓
  `getFileList` / `cover` 的原始响应；协议依据来自 NAS 自带前端 JS + `photos preview` 复核。
  电视上「目录封面 / 目录内缩略图 / 全屏大图 / 第二行滚动」的最终观感，
  仍需用本版安装包连接用户 NAS 确认。
