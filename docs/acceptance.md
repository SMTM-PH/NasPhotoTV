> 用法：把 APK 装到**目标设备**（Android TV / 电视盒子 / TV 模拟器，见 README §3.4）上用遥控器逐项走一遍，

## 0. 环境与安装

- [ ] `gradlew.bat :app:assembleDebug` 成功，产出 `app/build/outputs/apk/debug/app-debug.apk`
- [ ] `gradlew.bat :app:compileDebugKotlin` 无警告级错误（只跑编译即可，不需要 assemble）
- [ ] `adb install -r` 成功（电视需开启 ADB 调试；普通手机镜像需按 README §3.4 处理 leanback）
- [ ] 电视桌面/应用列表出现 **「NAS 相册 TV」**，图标与 banner 正常（`app_icon.png` / `app_banner.png`）
- [ ] `adb shell am start -n com.nasphoto.tv/.MainActivity` 能直接启动
- [ ] 启动后**全屏沉浸**：无状态栏、无导航栏、无标题栏
- [ ] 屏幕**不会自动休眠**（`FLAG_KEEP_SCREEN_ON`），静置 3 分钟仍亮屏
- [ ] 旋转/插拔 HDMI 后不崩溃（`configChanges` 覆盖 `screenSize|screenLayout|uiMode`）
- [ ] 冷启动 → 首屏可见 < 3 秒（Mock 数据下应 < 1 秒）
- [ ] `adb logcat -s AndroidRuntime:E` 全程无 FATAL EXCEPTION

## 9. 视频播放（VideoPlayerScreen，模拟播放）

## 14. 已知限制（验收时**不算缺陷**，见 README §8）

- 视频没有真实解码/声音（封面图 + 100ms 步进模拟进度）；`NAS 转码` 只影响角标文案
- 没有真实 NAS 连接（全部 Mock）；设置页「测试连接」是演示态（首次必失败一次），「重扫」是 1.5 秒假进度
- 字幕开关只显示一条样片中文（不解析 `.srt/.ass`）
- HEIC 只改扩展名，不涉及真实解码
- 星标不持久化（退出看图页即丢；不写回数据层）
- 「搜索」按钮只切 Tab，无搜索输入页
- 农历为锚点近似推算（锚点 2026-10-10 附近准确）
- 天气为按小时轮换的本地假数据
- 设置默认不落盘（外壳未调用 `restore()/persist()`，重启回默认值）
- 设置页的「账号」是在候选字母/序号间循环的演示值，不做真实认证
- 不支持长按/双击/手势（契约明确）
- 只有 1920×1080 画布的目测验证，无 4K 实测
- 媒体库/设置页的右栏统计（照片数/视频数）读的是 `MockData` 静态值
